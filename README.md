# Subnetting Tools

Página complementaria de **CIDR Visualizer**, enfocada en cuatro herramientas prácticas de IPv4: explorar prefijos, entender la frontera `/`, convertir decimal/binario y resolver subnetting.

## Qué incluye

1. **EXPLORE PREFIX** — slider `/0 → /32`, bits de red/host, total de direcciones, hosts utilizables, máscara y máscara binaria.
2. **UNDERSTAND THE / PREFIX** — comparación `/24 → /27` y explicación de cómo los bits pasan de host a red.
3. **CONVERT** — decimal → binario, binario → decimal y prefix → mask.
4. **SUBNETTING TOOL** — Network, Broadcast, rango utilizable, hosts, block size y una representación visual del bloque.

## Conexión con CIDR Visualizer

Este proyecto no reemplaza CIDR Visualizer. Lo complementa: **CIDR Visualizer explica el concepto; Subnetting Tools lo convierte en práctica y cálculo.**
